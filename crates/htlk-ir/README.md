# htlk-ir

IR compiler for the [Harness Toolkit](https://crates.io/crates/htlk).

This crate parses Harness Toolkit IR and compiles it into bytecode. Its domain
API will be introduced as the IR and bytecode requirements are defined.

See the [IR grammar](../../docs/ir-grammar.md) for the current language syntax.
