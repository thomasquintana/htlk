# Pinned protocol data

`mcp-2025-11-25.schema.json` is the MCP protocol's published JSON Schema snapshot.
Its source commit, URL and checksum are recorded in `mcp-source.json`; its upstream
license is included in `MCP-LICENSE`. Update with `node tools/update-mcp-schema.mjs`.

These files are declarative validation data consumed by native Rust code.
