# Executable registration and codec integration plan

Status: CBOR, digests, the executable envelope, lexical identifiers, canonical
types/ports, execution options, expressions, prompt templates, and local graph
definition records, execution profiles, libraries, and MCP identity/binding
records, bounded external JSON/JCS, policy records, and canonical-document
assembly/integrity checks are implemented under Draft 0.1. Runtime
registration and graph-level semantic verification remain unimplemented.
This is a greenfield project: no compatibility aliases or fallback formats exist.

Authority: `specs/compiler-spec.md`, `specs/htlk-executable.cddl`,
`specs/runtime-spec.md`, and the unified baseline in `specs/README.md`.
